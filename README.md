# SemiBook — 반도체 공정 인터랙티브 북

웨이퍼부터 패키징까지, 반도체 8대 공정을 **시각 자료와 브라우저 속 실험**으로 배우는 웹 교과서입니다.

🌐 **사이트:** https://z1n00-1015.github.io/semiwiki/

## 구성

| 장 | 주제 | 인터랙티브 실험 |
|---|---|---|
| 00 | 반도체 공정 한눈에 보기 | 밴드갭과 온도 · 15단계 NMOS 공정 단면 시뮬레이터 · 스케일 줌 · 무어의 법칙 피팅 |
| 01 | 웨이퍼 제조 | 초크랄스키 잉곳 성장기 · 다이 계산기(결함/수율) · 3D 결정면 뷰어 |
| 02 | 산화 | Deal–Grove 계산기 · LOCOS 버즈비크 · 박막 간섭색(프레넬+CIE) |
| 03 | 포토리소그래피 | 스핀 코터 · 레일리 해상도 · Abbe 공간상 시뮬레이터 · 오버레이 보정 게임 · EUV 광경로 |
| 04 | 식각 | 셀 오토마타 식각 프로파일(습식/RIE/Bosch) · 플라즈마 쉬스 이온 입사각 · 엔드포인트 게임 |
| 05 | 박막 증착 | PVD/CVD/ALD 스텝 커버리지 몬테카를로 · ALD 사이클 · 마그네트론 스퍼터링 |
| 06 | 이온 주입과 확산 | 질량 분석 자석 · 도핑 프로파일+어닐링 · 채널링 궤적 |
| 07 | 금속 배선과 CMP | 듀얼 다마신 스텝 · CMP 디싱/에로전 시뮬레이터 · 배선 저항 스케일링·RC |
| 08 | 테스트와 수율 | 웨이퍼 맵 · 수율 모델 비교 · 모놀리식 vs 칩렛 원가 |
| 09 | 패키징 | 패키지 진화 단면 · HBM+GPU 3D 분해도 · 인터커넥트 밀도 |
| 10 | 첨단 트랜지스터 | MOSFET 동작 · 게이트 구조별 라플라스 해 · Id–Vg 비교 · 노드 로드맵 |
| 부록 | 용어 사전 | 검색 · 장별 필터 |

각 장 끝에는 확인 퀴즈가 있으며, 진도는 브라우저에 저장됩니다. 라이트/다크 테마를 지원합니다.

## 기술

- 빌드 과정 없는 순수 HTML / CSS / JavaScript (Canvas 2D, SVG, CSS 3D)
- 외부 의존성: Pretendard 웹폰트(CDN)뿐
- `main` 브랜치에 푸시하면 GitHub Actions가 `gh-pages` 브랜치로 배포합니다.

## 로컬 실행

```bash
python3 -m http.server 8000
# http://localhost:8000 접속
```

> 모든 시뮬레이션은 실제 공정 물리를 바탕으로 한 **교육용 단순화 모델**입니다.
